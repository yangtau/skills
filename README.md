Personal agent skills.

- `skills/fix-todos/` — scan for TODO(<agent>)/FIXME(<agent>) markers and fix them
- `skills/simplify/` — quality pass over changed code (reuse, simplification, efficiency)
- `skills/lark-cli/` — unified router for all `lark-*` sub-skills of larksuite/cli (auth, IM, docs, sheets, calendar, VC, mail, tasks, approval, ...)
